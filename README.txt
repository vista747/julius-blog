julius's blog post instructions (for julius)
=======================

files:
- index.html
- style.css

how to make a post:
1) duplicate posts/myfirstpost.html and rename it
2) open the new file and change:
   - <title>
   - <h1>
   - the date inside <small> </small>
   - the body content
3) open index.html and add a new list item under the <ul>, for example:
   <li><a href="posts/newpost.html">example-post</a> <small>- example-date</small></li>
