arduino midi controller

2026 — code & composition — vcv rack & arduino leonardo — source code

During Georgia Tech’s pre-college program for Music Technology, I learned how to use VCV Rack and control patches utilizing an Arduino as a MIDI instrument. For the final presentation, I worked in a group of three people. Our instrument, which we called “G4ry,” used two joysticks similar to a gamepad to control the delay time and panning. When working on a patch with a mouse and keyboard, you can only control one parameter at a time. Adding physical controls like this allowed for more advanced control over the patch. We also used two potentiometers to control the lowpass cutoff and the reverb decay time.

I contributed the patch that we used for our demonstration and wrote all the Arduino code that made the instrument work. One of our group members was enthusiastic about adding a digital display to the device. This was a challenge for me because I had to quickly learn how to create an interactive UI for an IPS display. But it was worth it because it made our project unique and polished. It was fun to work in a group and share ideas while collaborating with my peers.
