2026 — design, code & composition — vcv rack & c++ — source code

After learning how to build synthesizer patches, I wanted to create my own VCV module. I was inspired by the Grain Delay effect in Ableton Live. I often use Grain Delay in my own music because of the glitchy and textured effect it adds to song elements. I wanted to use this same effect in VCV Rack, but there wasn’t an existing module that manipulated the audio exactly how I wanted, so I decided to use my knowledge of C++ to create it myself. I started by researching how to process audio grains in C++ and how to add multiple audio effects together efficiently. I referenced a version of Grain Delay recreated in Max for Live to understand the signal flow and how the grains are processed, which helped me implement similar logic in my module. The module works by continuously recording the input into a circular buffer, then layering multiple short grains that each play back from the buffer at their own pitch and delay. One of the challenges I encountered was ensuring that the grains were synchronized correctly with the buffer, which I solved by carefully managing the read and write pointers and implementing precise timing for grain playback.

To demo the finished module, I created an original composition that showcases the beautiful textures my module is able to produce. This project allowed me to combine my interests in modular synthesis and software development, and it was fun to implement my own ideas into a working VCV module.
