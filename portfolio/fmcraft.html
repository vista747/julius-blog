fmcraft

2026 — code & build — minecraft neoforge 1.21.11 — source code

For this project, I built a Last.fm integration Minecraft mod that scrobbles the Minecraft soundtrack to a user’s Last.fm account as it plays in game. I wanted to sharpen my Java skills and learn how to use the Last.fm API so I could apply it to other projects. I started by reading through the Last.fm API documentation to understand how to implement it in my code. Using the NeoForge ModDevGradle MDK for Minecraft 1.21.11, I built and tested the entire mod in the development environment. I also used a local SQLite database to store the song metadata that would be sent to Last.fm as it plays. Then, I implemented Last.fm API helpers to handle authentication, request signing, and communication with the web application. The most challenging part was figuring out how to format the data correctly so that the API would accept it. To let players interact with the mod without leaving Minecraft, I added commands that could be run using the in-game chat. Working on this project showed me that the tools I use to listen to music every day are all things I can build myself. This realization has inspired me to continue creating tools and projects that make music more personal and interactive.
